# Como executar o projeto

# 1. Entre na pasta do projeto.
cd trabalho01

# 2. Crie o ambiente virtual dentro da pasta do projeto.
python -m venv venv

# 3. Ative o ambiente virtual.
# CMD:
venv\Scripts\activate
# PowerShell:
.\venv\Scripts\Activate.ps1

# 4. Instale as dependências do projeto.
python -m pip install --upgrade pip
pip install -r requirements.txt

# 5. Inicie o servidor do projeto.
python manage.py runserver

# Para usar a página de integrantes, crie um arquivo .env nesta pasta com:
# SUPABASE_URL=sua_url_do_supabase
# SUPABASE_KEY=sua_chave_do_supabase
#
# O dashboard e as demais páginas não dependem dessa configuração.

# Observação:
# - Se estiver usando PowerShell e receber erro de execução de script, rode:
# Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
# - O comando acima deve ser executado dentro da pasta "trabalho01".
# - Se você estiver na raiz do repositório, primeiro use: cd .\trabalho01

# Para testar a recuperação de senha no Render com o Resend:
# 1. Crie uma API key no painel do Resend.
# 2. Adicione estas variáveis no Environment do serviço no Render:
# EMAIL_BACKEND=login.email_backend.ResendEmailBackend
# RESEND_API_KEY=sua_chave_do_resend
# DEFAULT_FROM_EMAIL=onboarding@resend.dev
# O remetente de teste do Resend só entrega para o e-mail da conta Resend.
# Para enviar a outros destinatários, verifique um domínio no Resend e use um remetente dele.

# Para os arquivos ZIP de produtos:
